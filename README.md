# Proyecto Clausura Cómputo Paralelo

Este proyecto implementa un análisis de frecuencia de palabras sobre varios libros clásicos, comparando una ejecución serial contra una paralela utilizando MPI.
La idea principal es sencilla: tomar varios textos, limpiarlos, contar cuántas veces aparece cada palabra y luego medir qué tanto mejora el rendimiento al distribuir el trabajo entre varios procesos.

Tecnologías usadas
C++
MPI (Message Passing Interface)
STL (unordered_map, map, vector, etc.)
Expresiones regulares (regex)
